# My Little Netflix

Aplicación web cliente para gestionar una base de datos de películas, hecha con HTML, CSS y JavaScript siguiendo el patrón **MVC**. Los datos se guardan en el `localStorage` del navegador y se pueden buscar películas en la API de **The Movie Database (TMDb)**.

Práctica de la asignatura **Tecnologías Web**.

## Funcionalidades

- Ver, añadir, editar y eliminar películas (con confirmación al borrar).
- Restablecer las películas iniciales (Reset).
- Buscar películas en TMDb y añadirlas a la lista local, evitando duplicados.


Datos de películas proporcionados por [TMDb](https://www.themoviedb.org). Este producto utiliza la API de TMDb pero no está avalado ni certificado por TMDb.
